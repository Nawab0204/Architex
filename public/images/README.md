# ACHITEX Image Asset Directory

This directory contains all the key photographic and vector assets used throughout the ACHITEX website. You can easily replace, swap, or update any image on the website simply by dropping your new image file into the corresponding folder with the exact same file name.

---

## Folder Structure & Image Specifications

### 1. Accreditations (`/public/images/accreditations/`)
These are the official regulatory bodies and chartered certification logos displayed across the homepage:
* **`Architects-registration-board-300x79.png`** (or `.svg`): Official ARB (Architects Registration Board) dot-matrix logo.

* **`chartered-town-planners-300x96.png`** (or `.svg`): RTPI Chartered Town Planner stepped-cube logo.

## How to Replace an Image:
1. Save your desired new image with the **exact same filename** (e.g. `hero-slide-1-contemporary-extension.jpg`).
2. Paste it directly into the matching subfolder.
3. Refresh your browser to see your new image immediately updated live on the website!
